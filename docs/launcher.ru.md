# Лаунчер Windows

Лаунчер даёт быстрый доступ к просмотру модели и обучению без ручного ввода команд PowerShell. В окне можно выбрать режим запуска, JSON-конфигурацию, скорость живого обучения, папку чекпойнта и число шагов для обучения в терминале.

## Visual Studio

1. Откройте `ArtificialLife.sln`.
2. Выберите проект **ArtificialLife.Launcher** как запускаемый проект.
3. Нажмите **F5**.

Проект находится в папке решения `tools`. Лаунчер запускает существующие скрипты `tools/run-godot.ps1` и `tools/train.ps1`, которые подготавливают SDK, собирают приложение и передают выбранные параметры.

## Visual Studio Code

Установите расширение C# Dev Kit, откройте репозиторий и нажмите **F5**, выбрав профиль **ArtificialLife: лаунчер**. Альтернативно выполните задачу **ArtificialLife: собрать лаунчер** через палитру команд.

## Режимы

- **Просмотр готовой модели** — запускает Godot с чекпойнтом `artifacts/checkpoints/thermal`.
- **Живое обучение в окне** — открывает Godot; скорость можно выбрать от 1× до максимальной. Клавиша **S** сохраняет веса в указанную папку чекпойнта.
- **Обучение в терминале** — запускает `tools/train.ps1` на заданное число шагов.

Перед первым запуском скачайте необходимые SDK и Godot командой `tools/bootstrap.ps1` или выполните её через терминал IDE. Для просмотра модели нужен уже созданный чекпойнт; его можно получить обучением в терминале или начать живое обучение.
